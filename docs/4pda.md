# Публикация на 4PDA

## 1. Куда создавать тему

Раздел: **Программы → Книги и справочники → Читалки** (название подраздела может
отличаться; при создании темы 4PDA показывает список, выберите ближайший по смыслу
и не создавайте тему в корне раздела). Если сомневаетесь, напишите модератору
раздела до публикации: перенесённая тема теряет счётчик и подписчиков.

Заголовок темы:

```
Manga Loader — читалка манги с офлайн-загрузкой [1.9.8]
```

Правила, которые чаще всего нарушают при первой публикации:

- APK прикрепляется к первому посту через файловый сервер 4PDA. Внешние ссылки
  можно дублировать, но они не заменяют вложение.
- Никаких реферальных и партнёрских ссылок, сокращателей и файлообменников
  с капчей.
- Шапка обновляется при каждом релизе: версия, дата, «Что нового», APK.
- Тема ведётся автором. Аккаунт должен быть не свежезарегистрированным: у новых
  аккаунтов первые сообщения проходят премодерацию.

## 3. Вложения к первому посту

1. `mangaloader-android-arm64-v8a.apk` — основной вариант для современных
   устройств.
2. `mangaloader-android-armeabi-v7a.apk` — для старых 32-битных устройств.
3. Три скриншота из `fastlane/metadata/android/ru-RU/images/phoneScreenshots/`.
4. Иконка приложения `assets/icon_monet.png` (для карточки темы).

Универсальный APK прикреплять не нужно: он втрое больше и нужен только для
x86-эмуляторов.

## 4. Обновление темы

При выходе новой версии:

1. Отредактируйте первый пост: версия, дата, `Что нового`, вложение APK.
2. Напишите сообщение в теме с коротким списком изменений и отметкой, что шапка
   обновлена.
3. Старый APK из вложения удалять не обязательно, но версию в заголовке темы
   менять нужно: модераторы ориентируются на неё.

## 5. Перед публикацией

- [ ] Тег `v1.9.8` запушен, GitHub Release собран.
- [ ] APK подписан тем же ключом, что и предыдущие релизы.
- [ ] F-Droid-репозиторий опубликован (workflow `Publish F-Droid repo`).
- [ ] Скриншоты соответствуют текущей версии.
- [ ] В шапке нет ссылок на файлообменники и реферальных ссылок.
- [ ] Указаны требования, лицензия и исходный код.
